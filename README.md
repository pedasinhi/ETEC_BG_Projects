# Projetos da ETEC

Aqui reúno exercícios, projetos e anotações das aulas da ETEC BG, separados por módulo e matéria. Há atividades em Python, HTML, CSS, JavaScript, C#, Dart, PHP e SQL.

| Módulo | Matéria | Conteúdo |
| --- | --- | --- |
| 1º | [Algoritmos e Programação](modulo-01/algoritmos-e-programacao) | Exercícios em Python e sistemas de alunos, clientes e vendas |
| 1º | [Programação Web I](modulo-01/programacao-web-i) | Páginas em HTML e CSS |
| 2º | [ADS](modulo-02/ads) | Projetos em C#, Windows Forms e ASP.NET Core |
| 2º | [Banco de Dados II](modulo-02/banco-de-dados-ii) | Scripts SQL, exercícios e materiais de aula |
| 2º | [Dart](modulo-02/dart) | Fundamentos da linguagem e orientação a objetos |
| 2º | [Programação Web II](modulo-02/programacao-web-ii) | Atividades de JavaScript e cadastros em PHP |

Cada pasta é uma atividade independente. Os números dos exercícios seguem a sequência das aulas, e as versões diferentes foram mantidas para consulta.

Para abrir as páginas de HTML, use o `index.html` da atividade. Os exercícios de Python precisam do Python 3. Os demais projetos usam o ambiente da própria linguagem; os arquivos de projeto indicam as versões e dependências. Nos exercícios de PHP, configure a conexão em `src/config/conexao.php` e importe o arquivo `database/schema.sql` no MySQL.

As pastas `anotacoes` e `materiais` guardam as explicações e os arquivos de apoio das aulas. Algumas atividades são rascunhos ou exercícios incompletos.
